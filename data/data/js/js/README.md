# Jeyson

Un muñequito que te espera, te pregunta, te cuida y construye su casa contigo.

## Qué toco si quiero cambiar algo

- `data/preguntas.js` → sus respuestas, secretos, parábolas, banco de preguntas del juego y su casa
- `data/config.js` → clave de Gemini y dificultad del minijuego
- `js/app.js`, `js/juego.js`, `js/anim.js` → el motor

## Clave de Gemini (gratis)

1. https://aistudio.google.com/apikey
2. Create API key (sin tarjeta)
3. Pégala en `data/config.js` o dentro de la app, en hablar → ajustes

## Publicarlo

1. Sube la carpeta a un repo público
2. Settings → Pages → Branch main, carpeta raíz → Save
3. Queda en https://tuusuario.github.io/jeyson
